# WolfEdu 0.9.5-beta.2

## Najważniejsze
- naprawiony natywny bridge `WolfSync` między WebView i Firebase
- Firebase Authentication + Firestore w Androidzie
- natywny eksport JSON przez systemowy selektor pliku
- wspólne dane realtime: szkoła, klasy, uczniowie, przedmioty, nauczyciele, plan, oceny, zadania, frekwencja
- spójny interfejs inspirowany Material 3
- 5-elementowa dolna nawigacja; pozostałe moduły dostępne z dashboardu
- poprawny package `pl.wolfedu.app` i nazwa `WolfEdu`
