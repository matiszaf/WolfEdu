# Współtworzenie WolfEdu

1. Nową funkcję opisz najpierw jako Issue.
2. Pracuj na gałęzi `feature/nazwa-funkcji` lub `fix/nazwa-bledu`.
3. Nie dodawaj plików keystore ani haseł do repozytorium.
4. Przed scaleniem sprawdź build w GitHub Actions.
5. Każda wersja musi mieć zwiększony `versionCode` i zaktualizowany `versionName`.

## Nazwy commitów

- `feat: dodano kalendarz`
- `fix: naprawiono obliczanie średniej`
- `ui: odświeżono ekran ocen`
- `docs: zaktualizowano roadmapę`
